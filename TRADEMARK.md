# Trademark & branding policy

The AGPL-3.0 license covering this project's code (see `LICENSE`) grants
broad rights to use, copy, modify, and redistribute the code, including
running modified versions — subject to AGPL's own conditions (in
particular, source disclosure for modified network services, per §13).

**Copyright and trademark are separate.** The license above does not grant
any right to use the project's name, "Dotfile Suite" branding, or logo.
That is governed by this policy instead.

## What's protected

- The project name and any associated wordmarks.
- The project logo/icon and other visual branding assets.
- Use of the name to describe a distribution, fork, or hosted service as
  being "official," "the" project, or endorsed by the maintainer.

## What you can always do

- Fork, modify, and redistribute the code under the AGPL, including
  commercially.
- Say, factually, that your project "is a fork of X" or "is based on X" —
  nominative/descriptive use for accurate attribution is fine.
- Use the name in unmodified redistribution of the project exactly as
  released.

## What requires permission

- Using the project name or logo as the name/branding of a modified fork,
  derivative application, or hosted service.
- Any use that could suggest your version is the official release, or is
  endorsed/maintained by the project.

## Applications built for this ecosystem

The same split applies to any applications developed for this OS/ecosystem:
their code is free to fork and modify under whatever open-source license
they're released with, but only versions integrated into the maintained,
canonical repository may use the project's name/branding as "the" official
app for a given purpose. Unmerged forks remain fully usable — they just
can't market themselves as the official one.

## Contact

To request permission for a branding use not covered above, open an issue
on this repository.
